# Legacy frontend

Esta carpeta agrupa compatibilidad visual heredada del frontend anterior.

## Zonas

- `html/active`: plantillas viejas que aun siguen activas por compatibilidad
- `html/archived`: plantillas antiguas archivadas, fuera del flujo principal
- `scripts/archived`: scripts heredados que ya no participan en la SPA activa

## Nota actual

En este momento solo el acceso/login sigue apoyandose en una plantilla legacy activa.
